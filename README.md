# FeelShareLove — lot 14

Version 1.6.0 (01/11/2026)
- Tribu sur invitation : « Inviter dans ma tribu », l'autre reçoit une notification
- L'invité répond toujours : « Accepter » ou « Répondre non » avec une des trois phrases toutes faites (pas de texte libre)
- Rappel chaque jour par notification tant que l'invité n'a pas répondu
- La réponse arrive à celui qui a invité, en clair, avec une notification ; nouvelle invitation possible un mois après un non
- Nouvelle liste privée « Mes personnes préférées » (bouton ☆ Personne préférée)
- Boutons « Personne préférée » et « Inviter dans ma tribu » sur le portrait, dans la conversation et dans le détail des résonances
- Page « Ma tribu » : À toi de répondre, Ma tribu, Invitations envoyées, Mes personnes préférées, Rencontrés ici
- Le « cercle intime » devient la tribu partout (vraie photo montrée à ma tribu)
- Mise à jour automatique : les choix réciproques deviennent la tribu, les choix à sens unique deviennent personnes préférées
- Inscription avec un lien d'invitation : les deux personnes sont directement dans la même tribu
- Page d'accueil, étape 4 : texte adapté à l'invitation
- Messages : le dernier message s'affiche sur deux lignes, précédé de « Toi : » ou du pseudo de l'autre
