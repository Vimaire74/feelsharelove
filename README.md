# FeelShareLove — lot 54 (regroupe les anciens lots 54, 55, 56 et 57)

Version 1.23.0 (11/11/2026)
- Un portrait n'apparaît dans les Résonances et dans Présent des autres que lorsqu'il est complet (photo, fonctionnement, date de naissance, langues, un métier ou rôle, un domaine du cœur, un genre d'histoires, trois choses qui font vibrer)
- Mon portrait : encadré jaune qui liste ce qui reste à remplir, vert quand le portrait est complet
- Résonances : encadré « Les autres ne te voient pas encore dans leurs résonances » avec le bouton « Compléter mon portrait »
- Création du compte : nouvel écran « Plus tu te montres, mieux on te trouve », montré une fois après la photo, avec le bouton « Je complète mon portrait »
- Aide et conditions : le même texte, relisible à tout moment
- Résonances : ce qu'une personne cache compte désormais dans le pourcentage, sans jamais être affiché
- Ce que les autres voient : bandeau clair « Aperçu », deux grands boutons pour choisir qui regarde, portrait entouré d'un cadre en pointillé
- Textes traduits dans les 5 langues

Fichiers : server/server.js, app/js/app.js, app/js/plus.js, app/js/pages/portrait.js, app/js/pages/resonances.js, app/js/pages/accueil.js, app/js/pages/now.js, app/js/pages/personne.js, app/js/pages/conditions.js, app/css/feelsharelove.css, app/js/lang/*.js
